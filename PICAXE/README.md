# PICAXE Programming

This folder contains programs for PICAXE microcontroller chips used for demonstrations.

## Getting Started

Each PICAXE project should be in its own subfolder with descriptive names.

## Structure

- Each project folder should contain:
  - `.bas` file(s) - The PICAXE BASIC program
  - `README.md` - Description of the project, chip model, components needed, and circuit diagrams
  - Any additional resources or documentation

## Usage

1. Connect your PICAXE programming cable
2. Open the program in PICAXE Programming Editor
3. Select the correct PICAXE chip model
4. Download the program to your chip
5. Follow the project-specific instructions in each folder's README
