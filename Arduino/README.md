# Arduino Scripts

This folder contains Arduino sketches and projects used for demonstrations.

## Getting Started

Each Arduino project should be in its own subfolder with descriptive names.

## Structure

- Each project folder should contain:
  - `.ino` file(s) - The Arduino sketch
  - `README.md` - Description of the project, components needed, and wiring diagrams
  - Any additional library dependencies or resources

## Usage

1. Open the `.ino` file in the Arduino IDE
2. Connect your Arduino board
3. Select the correct board and port from the Tools menu
4. Upload the sketch to your board
