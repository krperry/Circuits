# Breadboard Circuit Designs

This folder contains circuit designs and projects built on breadboards for demonstrations.

## Getting Started

Each breadboard project should be in its own subfolder with descriptive names.

## Structure

- Each project folder should contain:
  - `README.md` - Description of the circuit, learning objectives, and build instructions
  - Circuit diagrams (schematic and breadboard layout)
  - Bill of Materials (BOM) listing all components
  - Photos of completed circuit (if available)
  - Any code or programming if microcontrollers are used

## Usage

1. Review the project README and circuit diagrams
2. Gather all components from the BOM
3. Follow the breadboard layout diagram to build the circuit
4. Test and troubleshoot as needed
5. Follow project-specific instructions for operation

## Tips

- Always check component polarity (LEDs, electrolytic capacitors, diodes, etc.)
- Verify power supply voltage before connecting
- Use appropriate resistor values to protect components
- Keep wire lengths neat and organized for easier troubleshooting
